Task Scheduler
Enterprise Workflow Orchestration Engine
v1.0 Build: 2024-03-27
Java 11  ·  Oracle / MySQL  ·  Zero Middleware

Task Scheduler is a zero-middleware enterprise workflow orchestration engine built for Java / Oracle environments. It runs as a single JAR on Windows or Linux — no message broker, no registry, no container required. Developers register Task Types once; business users compose and operate workflows through a visual no-code DAG editor without writing a line of code.

Scheduling & Orchestration
  • ⏱ Cron scheduling via Netty HashedWheelTimer — 100 ms precision, hot-reload, no restart
  • 🔀 AND / OR gate DAG — built-in OR convergence, no workaround needed
  • 🔗 Synchronous nested sub-workflows with full parent-child callback & crash recovery
  • ⚡ Async HTTP trigger + EVENT zero-poll wait (CountDownLatch, DB-persisted)
  • 🔁 Five trigger modes: Cron / nested WORKFLOW / HTTP async / HTTP+EVENT / UI manual
Built-in Task Types
  • 🖥 Script — Shell / Python / CMD with real-time log capture
  • 🗄 SQL — DML · SELECT→JSON · ExportCSV · ExportExcel (streaming)
  • 🏛 Oracle — Stored Procedure (IN/OUT/INOUT) · DBMS_OUTPUT capture
  • 🌐 HTTP — 5 auth modes (NONE / BASIC / BEARER / API_KEY / HYBRID auto-login)
  • 📁 FileX — file / FTP / SFTP; copy · move · sync
  • ⚙️ DataX — inline JSON or file-path mode; heterogeneous data sync
  • 🔒 LOCK · ⏳ WAIT · 📡 EVENT · ⑂ OR · 🔄 WORKFLOW · ☕ JAVA
  • 🧩 Extensible — register any custom TaskType via DB + classpath
Operations & Control
  • ✅ Per-task Retry / Skip / Cancel — state-aware, no full workflow restart
  • ♻️ Workflow Recover — precise checkpoint resume after JVM restart
  • ⛔ Cascaded cancel — workflow cancel propagates recursively to all sub-workflows
  • ⏱ TIMEOUT as an independent terminal state (distinct from ERROR)
  • 🔐 Built-in distributed mutex lock (TS_LOCK table, auto-release on cancel)
  • 📧 Email notifications: START / END / ERROR / TIMEOUT / CANCEL — independent flags
Parameters & Visibility
  • 📐 3-level parameter inheritance: Global → Workflow → Task with {variable} substitution
  • 💾 saveParam() persists task output to DB — downstream tasks read automatically
  • 📊 D3 Gantt chart — workflow + task dual-layer, collapse/expand, SVG export
  • 🔍 Real-time DAG view with per-node status, duration, and error highlight
  • 📋 Task Details — live parameter map + execution log side by side
  • 📤 Excel import/export — cross-environment workflow deployment in one click
